HOW IT WORKS

01
📷

Camera Capture

OpenCV captures live video from your webcam at up to 60fps, flipping the frame for a mirror-like natural interaction experience.

02
🧠

MediaPipe Detection

Google's MediaPipe Hands model detects 21 key landmarks on your hand in real-time with 70%+ confidence threshold.

03
📐

Gesture Mapping

Finger states and tip distances are calculated mathematically to classify which gesture you're performing each frame.

04
⚡

PyAutoGUI Execution

Detected gestures instantly trigger OS-level mouse and keyboard actions via PyAutoGUI with minimal latency.

05
🔊

System Controls

Volume is controlled via Windows Core Audio API (pycaw), brightness via screen_brightness_control library.

06
🖥️

Visual Feedback

Real-time on-screen labels show the active gesture in the OpenCV window, so you always know what's being detected.

ALL GESTURES

☝️
Cursor Move
Index finger only up. All other fingers must be down. Thumb must not touch index. Index tip maps to screen coordinates.
Mouse
👌
Single Click
Thumb tip touches index tip with all fingers down. Triggers left click at current cursor position.
Mouse
👌
Double Click
Thumb touches index tip twice within 0.4 seconds. All other fingers must be down.
Mouse
🖕
Right Click
Middle finger only up. Index, ring and pinky must be down. Opens context menu instantly.
Mouse
✌️
Scroll Up
Index + Middle fingers up, ring + pinky down. Move hand close to camera (hand looks big on screen).
Mouse
✌️
Scroll Down
Index + Middle fingers up, ring + pinky down. Move hand far from camera (hand looks small on screen).
Mouse
🤞
Zoom In
Middle + Ring fingers up, index + pinky down. Move hand close to camera. Triggers Ctrl + on active window.
Control
🤞
Zoom Out
Middle + Ring fingers up, index + pinky down. Move hand far from camera. Triggers Ctrl - on active window.
Control
🤙
Volume Up
Index + Pinky up, middle + ring down. Move hand close to camera. Volume increases continuously with depth.
Control
🤙
Volume Down
Index + Pinky up, middle + ring down. Move hand far from camera. Volume decreases continuously with depth.
Control
🌟
Brightness Up
Pinky finger only up. Index, middle and ring must be confirmed down. Move hand close to camera. Increases by 10%.
Control
🌑
Brightness Down
Pinky finger only up. Index, middle and ring must be confirmed down. Move hand far from camera. Decreases by 10%.
Control
🖐️
Screenshot
All 4 fingers open (index, middle, ring, pinky all up). Saves PNG with timestamp. 2 second cooldown between shots.
System
✊
Lock System
Closed fist with all fingers down and thumb away from index. Hold for 2 seconds. Countdown shown on camera window.

Installation

QUICK SETUP

01

Create Virtual Environment

Set up an isolated Python environment for the project

python -m venv gesture_env
02

Activate Environment

Activate the virtual environment in PowerShell

gesture_env\Scripts\activate
03

Install Dependencies

Install all required Python packages

pip install opencv-python mediapipe pyautogui pycaw comtypes screen-brightness-control
04

Run the Script

Launch the gesture control system

python main.py
05

Allow Camera Access

Grant webcam permissions when prompted. Press Q to quit.

Allow camera → Start gesturing
